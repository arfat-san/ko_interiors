 KO Interior Studio – Portfolio Website

This repository contains the frontend code for the KO Interior Studio portfolio website, showcasing luxury residential and commercial interior design projects, services, and brand story.

 Project Overview

The website is a multi-page static site built with HTML, CSS, and JavaScript to present KO Interior Studio’s design philosophy, services, and portfolio in an elegant, user-friendly way.[file:5][file:1][file:3]

Key highlights:
- Focus on luxury residential and commercial interior design.[file:5]
- Story-driven “About” section introducing Principal Interior Designer Komal Thorat and the studio’s philosophy.[file:1]
- Portfolio section featuring curated projects and visual storytelling.[file:3]
- Contact page for inquiries and consultation requests.[file:4]

 Pages

- `index.html` – Landing page with hero section, services overview, process, testimonials, and social links.[file:5]
- `aboutus.html` – Detailed background of KO Interior Studio and Principal Interior Designer Komal Thorat.[file:1]
- `portfolio.html` – Showcases selected interior design projects and visual highlights.[file:3]
- `contact.html` – Contact form and studio contact details for client inquiries.[file:4]
- `index2.html` – Alternate or experimental home/section layout (can be used for A/B testing or future redesigns).[file:2]

Features

- Clean, modern layout emphasizing imagery and typography suitable for luxury interiors.[file:5][file:3]
- Structured content for services, process, testimonials, and project highlights.[file:5][file:3]
- Multi-page navigation for clear separation between About, Portfolio, and Contact flows.[file:1][file:3][file:4]

 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser to view the site locally.
3. Use a simple HTTP server (e.g., `python -m http.server`) if you need to test navigation, assets, or relative paths.

 Technologies Used

- HTML5 for page structure.[file:5]
- CSS3 for layout and styling (linked stylesheets within the HTML files).[file:5]
- JavaScript for interactive behavior where applicable (e.g., navigation, UI effects).[file:2][file:5]

Customization

You can customize the content and visuals by editing:
- Text sections in each HTML file (hero copy, about text, services, testimonials, etc.).[file:1][file:5]
- Images and portfolio entries in `portfolio.html` and related assets.[file:3]
- Styles in the linked CSS files to match updated branding or color palettes.[file:5]

Deployment

This project can be hosted on any static hosting provider, such as:
- GitHub Pages
- Netlify
- Vercel
- AWS S3 static website hosting

Simply upload all HTML, CSS, JS, and asset files, ensuring relative paths remain intact.
